Cách 1: Extension trình duyệt Khuyên dùng · Không cần dòng lệnh · Đa nền tảng

Dùng một tiện ích mở rộng trình duyệt nhỏ, giúp bạnmuse đã đăng nhập sẵn trên máy tính của bạn.ai Trạng thái đăng nhậpđồng bộ sang. Không cần cài Python, không cần mở terminal, không cần gõ lệnh.
Tại sao phải dùng extension：muse.ai đều mang đủ 4 Cookie cốt lõi của httpOnly đánh dấu, script trang web (gõ trong F12 document.cookie、 bookmarklet) không đọc được; chỉ có extension trình duyệt cookies API có thể lấy được.
1
Tải xuống và giải nén tiện ích mở rộng
Giải nén vào một thư mục bạn sẽ không xóa, ví dụ: D:\muse2api-extension。
⬇ Tải xuống muse2api-extension.zip
2
Tải extension vào trình duyệt
Lấy Chrome làm ví dụ (các trình duyệt nhân Chromium như Edge / Brave / 360 Cực Tốc có các bước tương tự):
  1. Nhập vào thanh địa chỉ chrome://extensions Enter
  2. Mở góc trên bên phải Chế độ nhà phát triển Bật/Tắt
  3. Bấm vào góc trên bên trái Tải tiện ích mở rộng đã giải nén
  4. Chọn thư mục đã giải nén ở bước 1Thư mục（không phải tệp đơn lẻ bên trong)
3
Đăng nhập muse.ai，Sau đó nhấp vào biểu tượng extension để nhập
Hãy mở trong trình duyệt của bạn trước https://muse.ai/ và đăng nhập (đăng nhập cho đến khi nhìn thấy giao diện chat), sau đó nhấp vào biểu tượng tiện ích trên thanh công cụ trình duyệt, điền hai mục bên dưới vào rồi nhấp「Đọc và nhập」。

Cách 2: Sao chép thủ công Không cần cài đặt · Phương án dự phòng

Nếu không muốn cài tiện ích mở rộng, bạn có thể trích xuất thủ công chuỗi Cookie. Điểm mấu chốt là dùng 「Mạng」Request Header của bảng điều khiển，chứ không phải Console — trong Header yêu cầu cookie: Một dòngBao gồm các mục có httpOnly，Console Không đọc được.
  1. Mở và đăng nhập trong trình duyệt của bạn https://muse.ai/，Dừng tại giao diện trò chuyện
  2. Theo F12 Mở Công cụ dành cho nhà phát triển, chuyển sang Mạng / Network Bảng điều khiển
  3. Theo F5 Làm mới trang để danh sách yêu cầu hiển thị nội dung
  4. Nhấp vào danh sáchBất kỳ mục muse nào.ai yêu cầu（cái đầu tiên là được)
  5. Tìm thấy ở bên phải Tiêu đề / Headers → Cuộn xuống đến Tiêu đề yêu cầu / Request Headers
  6. tìm thấy với cookie: dòng bắt đầu bằng, Sao chép toàn bộ chuỗi ký tự phía sau dấu hai chấm （Từ hatch_sess= bắt đầu, cho đến hết dòng)
  7. Dán vào bên dưới「Phương thức 3」vào ô nhập, nhấp Nhập
Lưu ý: làRequest Headertrong cookie:，Không phải「Response Header」。 trong header phản hồi set-cookie Chỉ có một phần Cookie, sẽ bị thiếu dữ liệu.

Cách 3: Dán để nhập / Script máy cục bộ Nâng cao

Nếu đã có chuỗi Cookie, hãy dán trực tiếp vào đây để import (chuỗi sao chép thủ công ở Cách 2 cũng dán vào đây).
Nếu bạn quen dùng dòng lệnh hoặc muốn đăng nhập bằng trình duyệt độc lập (không động đến trình duyệt hàng ngày), bạn cũng có thể dùng script này. Nó chỉ sử dụng thư viện chuẩn của Python,Không cần pip install bất kỳ thứ gì。

Vì vậy: Cứ khoảng 2 ngày cần nhập lại một lần.May là rất nhanh — chỉ cần nhấp vào biểu tượng extension là xong.

2. Trò chuyện / Viết mã

Sao chép# Non-stream
curl -X POST "BASE/v1/chat/completions" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"muse-spark","messages":[{"role":"user","content":"Viết một thuật toán QuickSort bằng Python"}]}'

# Stream: Thêm "stream":true，Trả về SSE chuẩn (data: {...} / data: [DONE]）

3. Tạo ảnh (curl)

Sao chépcurl -X POST "BASE/v1/images/generations" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Một chú chó Shiba đeo mũ phi hành gia","size":"1:1","response_format":"url"}'

# Quay lại
{"created":1790148495,"data":[{
  "revised_prompt":"Một chú chó Shiba đeo mũ phi hành gia",
  "url":"http://your-server:18610/v1/media/xxxx.webp",
  "kind":"image","bytes":23860}]}

# url là địa chỉ tuyệt đối đầy đủ, có thể cung cấp trực tiếp cho downstream để render / tải xuống; /v1/media/* Không cần xác thực.
# Nếu muốn lấy base64 thì truyền "response_format":"b64_json"。

4. Tạo video (curl, bất đồng bộ)

Sao chép# ① Tạo tác vụ
curl -X POST "BASE/v1/videos" \
  -H "Authorization: Bearer $MUSE2API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Một chú mèo con đang đi dạo trên bãi cỏ","duration":5,"size":"16:9"}'
# → {"id":"task_xxx","status":"queued"}

# ② Kết quả polling
curl "BASE/v1/videos/task_xxx" -H "Authorization: Bearer $MUSE2API_KEY"
# → {"status":"succeeded","result":{"url":"/v1/media/xxx.mp4"}}

5. Python（openai SDK tương thích)

Sao chépfrom openai import OpenAI
import time

client = OpenAI(base_url="BASE/v1", api_key="m2a_...")

# Tạo ảnh
r = client.images.generate(model="muse-image", prompt="Một chú chó Shiba đeo mũ phi hành gia")
print(r.data[0].url)

# Tạo video (dùng API gốc vì là tác vụ bất đồng bộ)
import requests
t = requests.post("BASE/v1/videos", json={"prompt":"Mèo con đi lại","duration":5},
                  headers={"Authorization":"Bearer m2a_..."}).json()
while True:
    s = requests.get(f"BASE/v1/videos/{t['id']}",
                     headers={"Authorization":"Bearer m2a_..."}).json()
    if s["status"] in ("succeeded","failed"): break
    time.sleep(5)
print(s)

Giới thiệu「Gọi công cụ」giới hạn này (Quan trọng, đã kiểm tra thực tế):
muse.ai của trợ lý web với 「Xuất JSON giả lập Tool Call」có chính sách từ chối rõ ràng — nguyên văn kiểm thử thực tế là 「Tôi sẽ không xuất theo định dạng JSON này'Gọi tool giả lập'——Tôi không có công cụ get_weather này」。 Đã thử tương thích bằng 3 giao thức prompt với cách diễn đạt và vị trí khác nhau, tất cả đều thất bại.
Vì vậy: Phụ thuộc vào tool_calls củaChế độ Agent tự chủ（như tự động đọc/ghi tệp, thực thi lệnh) không hỗ trợ; nhưng tất cảDạng hỏi đápCách dùng —— Trò chuyện, viết code, giải thích, dịch thuật, tóm tắt, tạo ảnh, tạo video —— Tất cả đều khả dụng。
Nếu Client cố tình gửi kèm tools trường này, API sẽ không báo lỗi mà bỏ qua khai báo công cụ, phản hồi bình thường như hội thoại thông thường.
